# User Request (Raw, Unedited)

使用 TypeScript + Vite + THREE.js 构建一款2D玩法3D渲染的弹幕射击游戏：
- 游戏背景：高科技星际军事基地，冷酷森严的战争基调和色彩氛围。
- 玩家操控一架飞机，按ADSW控制方向，自动射击子弹，竖向，从屏幕下方向上射击。
- 游戏开始时，玩家可以从三架飞机中选择一架，三架飞机具有不同的美术造型和子弹攻击方式，主要偏向于宇宙战机风格。
- 在游戏中，玩家可以拾取2种类型的道具：POWER，和僚机。
  - POWER可以用于增加子弹威力，不同飞机具有不同的增强方向，例如子弹数量，子弹散射，宽度等。
  - 僚机可以为飞机增加随行战斗置。僚机跟随者玩家飞机的飞行轨迹后方，最多可以安装5个僚机。僚机有5种类，不同种类的僚机能够产生不同的攻击效果，例如：子弹，激光，跟踪导弹等。
  - 如果威力满了,拾取的POWER后就不再增加威力,只增加分数。
  - 如果僚机满了，最早拾取的僚机会被移除，并添加新僚机。
- 设计出3款基础敌人战机+4款精英敌人战机+3个Boss，具有不同的攻击方式、尺寸和造型。
- 设计出3个关卡，关卡需要配置出敌机出场顺序与流程，三个关卡具有不同的风貌。
- 关卡采用循环拼接模块的方式实现，例如一个科技穿梭通道无限地头尾相接，而且模块随着玩家飞机的前进，动态生成和回收。
- 所有战机的设计都要很帅气。
- 游戏需要有华丽的特效，受击效果和爆炸特效，帅气的玩家飞机出场画面和敌机出场画面。
- 使用高效的子弹回收机制。
- 主界面+飞机选择界面+每个关卡的通关结算界面+GameOver界面，界面有科幻设计感。
- 使用12到15个垂直切片。
